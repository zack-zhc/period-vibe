# 历史记录页面空状态样式调整

## 概述

根据提供的 HTML 原型调整历史记录页面的空状态，并添加公用的顶部标题区域。

## 修改内容

### 1. 公用顶部区域（新增）

在所有状态下（有数据/无数据）都显示：
- 大标题："你的旅程"（headlineLarge 样式）
- 描述文本："追踪你的周期，发现规律和洞察"（bodyLarge 样式，onSurfaceVariant 颜色）
- 间距：标题与描述间距 8dp，整体顶部 padding 16dp

### 2. 空状态设计（按原型）

- 使用 Surface 容器卡片：
  - 圆角：20dp
  - 背景色：surfaceContainer
  - 边框：surfaceContainerHigh
- 居中布局
- **无大图标**（原型中没有）
- 标题："还没有记录"（titleLarge 样式）
- 描述："记录你的第一次经期，开始追踪你的旅程并发现你个人的周期规律。"（bodyLarge 样式，居中对齐，maxWidth 限制）
- 按钮："去记录"（Button 样式，圆角 full，带加号图标）

### 3. 有数据时的内容

- 公用顶部区域（新增）
- 统计卡片（保持现有样式不变）
- 时间线周期卡片（保持现有样式不变）

### 4. 保持不变的部分

- TopAppBar（返回按钮 + "历史记录"标题 + 编辑按钮）
- 编辑模式和批量删除功能
- 时间线展开/折叠功能
- 深色/浅色主题支持

## 修改文件列表

| 文件 | 修改内容 |
|------|---------|
| HistoryScreen.kt | 添加公用顶部区域，重写 EmptyState 组件 |

## 注意事项

- 所有文本使用中文
- 不添加装饰性模糊背景效果（保持简单设计）
- 按钮文本保持"去记录"
